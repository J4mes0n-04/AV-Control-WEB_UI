# vozmozhnosti — веб-поверхности продукта

## Назначение папки

Здесь лежат **отдельные возможности (capabilities) WEB UI/UX**. Каждая подпапка — одна логическая веб-поверхность или сквозной слой интерфейса. Структура сделана так, чтобы агент и OpenSpec могли однозначно сопоставить папку с путём `openspec/specs/<capability>/spec.md`.

OpenSpec не сканирует `src_req`. Имена подпапок на лatinице — это **будущие идентификаторы capability**; русские названия и смысл — в README каждой подпапки и в будущих файлах содержимого.

## Подпапки

| Папка | Продуктовый смысл | Модуль пакета (ориентир) |
|-------|-------------------|---------------------------|
| `konfigurator/` | Веб-настройка серверного и клиентского проекта (замена Studio) | M-PRJ |
| `klient-komnaty/` | Веб-клиент управления комнатой, браузер и киоск на панели | M-ROOM |
| `admin-kontroller/` | Веб-эксплуатация контроллера для IT Admin | M-ADM (экранная часть) |
| `obshchiy-interfejs/` | Сквозной UX: вход, роли на экране, ошибки, offline, пустые состояния | PRD NFR-UX, FR-SEC/ROOM на уровне UI |

## Единый шаблон внутри каждой capability

В каждой подпапке планируются три файла (пока не созданы):

| Файл | Назначение | Куда в OpenSpec |
|------|------------|-----------------|
| `naznachenie.md` | Зачем эта поверхность, для кого, что входит и не входит | `proposal.md` → Why, Capabilities |
| `povedenie.md` | Наблюдаемое поведение на экране, сценарии, тексты | `specs/<capability>/spec.md` |
| `granicy.md` | P0/P1/P2 для этой поверхности, отложенное и «не делаем в UI» | `proposal.md` → Impact; уточнение scope |

## Что не выносится в отдельные папки

M-DRV, M-VAR, M-AUT, M-MON, M-LIC, M-UPD, открытый API как backend — **не отдельные папки** в этом репозитории. Если пользователь **видит** статус драйвера, тега или сценария на экране, описание пишется в `povedenie.md` той поверхности, где это отображается (чаще `konfigurator`, `klient-komnaty` или `admin-kontroller`).

## Источник

Фрагменты из «Консолидированного пакета» режутся по экрану и роли, а не копируются целиком по номеру документа 1–7.
