# admin-kontroller — веб-администрирование контроллера

**Capability (OpenSpec):** `admin-kontroller`  
**Продукт:** эксплуатация контроллера через веб для IT Admin.  
**Основной пользователь:** IT Admin.

## Назначение папки

Здесь хранится описание **административных экранов** в браузере: состояние сервера/контроллера, перезагрузка при наличии прав, настройка сети и времени (NTP) через UI, первый администраторский пользователь (если это wizard на экране), раздача проектов на клиенты и контроль версий **как видит администратор**, мониторинг подключённых клиентов на панели.

Safe Mode, автозапуск проекта, проверка целостности — в пакете относятся к жизненному циклу (M-LCM). В этой папке фиксируется только **что админ видит и может сделать в вебе** (индикатор Safe Mode, кнопки, предупреждения), без описания серверного алгоритма.

## Что здесь будет храниться

| Файл (план) | Содержание |
|-------------|------------|
| `naznachenie.md` | Зачем отдельная admin-поверхность, отличие от конфигуратора проекта и от клиента комнаты |
| `povedenie.md` | FR-ADM-* и связанные сценарии: dashboard состояния, перезагрузка, сеть/время, клиенты, выдача проекта |
| `granicy.md` | Что остаётся на сервере без UI; P0/P1; что не дублировать из M-MON (health) — только если это тот же экран |

**Источники пакета:** PRD M-ADM (`FR-ADM-*`), Scope §1.10, фрагменты M-MON про health dashboard, если он в admin UI.

## Чего здесь не должно быть

- Offline-обновление прошивки как процесс на диске (M-UPD) — только экран «обновление доступно / установлено / ошибка», если такой UI есть.
- RBAC и политика паролей как серверные правила (M-SEC) — только экраны пользователей/ролей, если они в этом приложении.
- Лицензирование как криpto/активация — только **понятный статус лицензии на экране** (FR-LIC UX), кратко в `povedenie.md` или отсылка к admin-разделу.

## Связь с OpenSpec

Изменения admin UI оформляют отдельными changes с spec `admin-kontroller`. Пересечения с `obshchiy-interfejs` (вход, права «кнопка неактивна») описывают явными ссылками, не дублируют целиком.
